Полный full-stack проект в стиле Netflix. Next.js 16, React 19, Prisma + PostgreSQL, Tailwind CSS 4, Framer Motion, Video.js и Shadcn UI. Бэкенд с нуля: описываем модели, наполняем базу сидером, выстраиваем API. На фронте — страница сериала, модальное окно с видеоплеером на Video.js, прогресс-бар по сериям и карусель на Embla.
